🌸 BLOOM — Your Little Productivity Space

BLOOM is a personal productivity desktop application built with Python and Tkinter.

It helps users organize their plans, goals, habits, notes, and progress in one beautiful workspace.

✨ Features

📋 Manage daily plans
🎯 Create and track goals
📅 View plans and activities on a calendar
🌱 Track habits and streaks
📊 Monitor productivity progress
📝 Create, edit, and organize notes
🌙 Switch between light and dark themes
💾 Save data permanently using JSON
🔄 Automatically save data
🛠️ Technologies Used

Python
Tkinter
JSON
Calendar module
Object-oriented GUI concepts
▶️ How to Run BLOOM

Requirements
Python 3 installed
A computer running Windows, macOS, or Linux
Steps
Download or clone this repository.
Open the project folder.
Run the following command:
python bloom.py
BLOOM will open as a desktop application.
#💾 Data Storage

BLOOM automatically saves plans, goals, habits, and notes in a local JSON file named:

bloom_data.json

This file is created automatically when the application saves data.
